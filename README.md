# 时笺

在线地址：https://bamboo7283.github.io/xufeibu/

记录每个 App 会员的套餐、续费日期和金额，到期前通过系统「日历」提醒。纯网页小工具，不需要服务器，数据保存在你自己的设备上，可选用 GitHub 在 iPhone 和 Mac 之间自动同步。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面入口 |
| `styles.css` | 样式（清新的毛玻璃风格、深浅色模式、动效） |
| `app.js` | 全部功能 |
| `sw.js` | 离线缓存，让它像 App 一样没网也能打开 |
| `manifest.webmanifest`、`icons/` | 添加到主屏幕后的名字和图标 |

## 在 iPhone 和 Mac 上用

iPhone 需要通过一个网址打开它，最省事的免费办法是放到 GitHub Pages：

1. 登录 [github.com](https://github.com)（没有账号就注册一个）。
2. 右上角 **+ → New repository**，名字填 `xufeibu`，选 **Public**，创建。
   公开的只是这几个程序文件，你的会员数据不会上传，它们只存在你的设备里。
3. 在新仓库页面点 **uploading an existing file**，把 `index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.webmanifest` 和 `icons` 文件夹一起拖进去，点 **Commit changes**。（`.claude` 文件夹不用传。）
4. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
5. 等一两分钟，页面顶部会出现网址，形如 `https://你的用户名.github.io/xufeibu/`。

然后：

- **iPhone**：用 Safari 打开这个网址 → 点底部「分享」→「添加到主屏幕」。之后从主屏幕图标打开，就是全屏 App 的样子，没网也能用。
- **Mac**：用 Safari 打开同一个网址 → 菜单栏「文件」→「添加到程序坞」，就会变成一个独立的 Mac App。

想分享给朋友，把网址发给他们就行。每个人的数据各存各的，互相看不到。

> 只在 Mac 上临时看看的话，也可以直接双击 `index.html` 打开，但这样存的数据和上面网址里的数据是分开的。

## 提醒

- **推荐：订阅日历。** 开启同步后，在「⋯ → 订阅到日历」点一次订阅，「日历」里会多出一个「时笺」日历：每个会员的到期日都在上面，到期前按你设定的天数在早上 9 点提醒，并按续费周期自动重复。以后增删改会员，日历会自动更新（大约每小时刷新一次）。
- 订阅后要打开提醒：iPhone「设置 → App → 日历 → 日历账户 → 已订阅的日历 → 时笺」，关掉「移除提醒」；Mac 订阅时在弹窗的「移除」里取消勾选「提醒」。
- iPhone 主屏幕 App 打不开页面里生成的日历文件，所以 iPhone 上只能用订阅。Mac 浏览器里没开同步时，「加到日历」会下载一个 `.ics` 文件，双击加到「日历」。
- 网页没法直接写入「提醒事项」App，所以提醒走的是「日历」。

## 数据与同步

- 数据先保存在每台设备的浏览器里。
- **自动同步（推荐）：** 在「设置」里用 GitHub 令牌开启同步，数据会存进你 GitHub 账号下的一个 secret gist（不公开、搜不到，但拿到链接的人能看到），iPhone 和 Mac 打开时、切回前台时、每 30 秒、以及每次修改后都会自动同步。同一个会员两边都改了，以较新的修改为准；删掉的不会被加回来。
- 令牌只保存在各自设备上，只有 gist 权限。不想同步了，在「设置」里点「断开」即可。
- 没开同步时也可以手动：「⋯ → 导出备份」，在另一台设备「⋯ → 导入备份」选「合并」。
- 清理 Safari 网站数据、或删掉主屏幕图标，会清掉那台设备上的数据；开了同步的话，重新连接就能从云端恢复。

## 以后修改程序

改完文件后，把 `sw.js` 里 `CACHE` 的版本号加一（如 `xufeibu-v6` → `xufeibu-v7`），再重新上传到 GitHub。已经装到主屏幕的 App 下次打开时会在后台更新，再打开一次就能看到新版本。
