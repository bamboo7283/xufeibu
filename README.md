# 时笺

在线地址：https://bamboo7283.github.io/xufeibu/

记录每个 App 会员的套餐、续费日期和金额，到期前通过系统「日历」提醒。纯网页小工具，不需要服务器，数据只保存在你自己设备的浏览器里。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面入口 |
| `styles.css` | 样式（清新的毛玻璃风格、深浅色模式、动效） |
| `app.js` | 全部功能 |
| `sw.js` | 离线缓存，让它像 App 一样没网也能打开 |
| `manifest.webmanifest`、`icons/` | 添加到主屏幕后的名字和图标 |

## 在 iPhone 和 Mac 上用

iPhone 需要通过一个网址打开它，最省事的免费办法是放到 GitHub Pages：

1. 登录 [github.com](https://github.com)（没有账号就注册一个）。
2. 右上角 **+ → New repository**，名字填 `xufeibu`，选 **Public**，创建。
   公开的只是这几个程序文件，你的会员数据不会上传，它们只存在你的设备里。
3. 在新仓库页面点 **uploading an existing file**，把 `index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.webmanifest` 和 `icons` 文件夹一起拖进去，点 **Commit changes**。（`.claude` 文件夹不用传。）
4. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
5. 等一两分钟，页面顶部会出现网址，形如 `https://你的用户名.github.io/xufeibu/`。

然后：

- **iPhone**：用 Safari 打开这个网址 → 点底部「分享」→「添加到主屏幕」。之后从主屏幕图标打开，就是全屏 App 的样子，没网也能用。
- **Mac**：用 Safari 打开同一个网址 → 菜单栏「文件」→「添加到程序坞」，就会变成一个独立的 Mac App。

想分享给朋友，把网址发给他们就行。每个人的数据各存各的，互相看不到。

> 只在 Mac 上临时看看的话，也可以直接双击 `index.html` 打开，但这样存的数据和上面网址里的数据是分开的。

## 提醒

- 在会员详情里点「加到日历」（或右上角「⋯ → 全部加到日历」），会生成一个日历事件，到期日前按你设定的天数在早上 9 点提醒，并按续费周期（每月、每年……）自动重复。
- iPhone 上点「打开日历邀请」后选「全部添加」即可；Mac 上会下载一个 `.ics` 文件，双击它加到「日历」。
- 只要 iCloud 日历是打开的，iPhone 和 Mac 会一起提醒。
- 标记停订或改了到期日之后，记得去「日历」里删掉旧的事件，再重新「加到日历」。
- 网页没法直接写入「提醒事项」App，所以提醒走的是「日历」。

## 数据与备份

- 数据保存在各自设备的浏览器里，**iPhone 和 Mac 之间不会自动同步**。
- 同步办法：在一台设备上「⋯ → 导出备份」（iPhone 上可以存到 iCloud 云盘），在另一台设备上「⋯ → 导入备份」，选「合并」：两边的会员都会保留，同一个会员以最近修改的为准，删掉的也不会被加回来。
- 清理 Safari 网站数据、或删掉主屏幕图标，都可能把数据一起清掉，定期导出一份备份比较安心。

## 以后修改程序

改完文件后，把 `sw.js` 里的 `xufeibu-v1` 改成 `xufeibu-v2`（每次加一），再重新上传到 GitHub。已经装到主屏幕的 App 下次打开时会在后台更新，再打开一次就能看到新版本。
