# 续费手账 · 小红书小工具版

## 上传文件

上传 [`dist/renewal-ledger-xhs-v2.zip`](dist/renewal-ledger-xhs-v2.zip)。v2 修复了首次打开时，原生存储返回空字符串导致的读取报错。ZIP 根目录只有 `index.html`、`app.js`、`backup.js`，不需要再压缩外层文件夹。当前页面名称暂定为「续费手账」；平台后台填写的名称也建议使用这个名字。

## 功能与容器适配

- 保留会员、大类、套餐、金额、周期、到期日、续费历史、停订、汇率估算与筛选等原有核心功能。
- 到期提示在打开小工具或重新切回前台时刷新，并按每项设置的提前天数显示；小红书小工具目前不提供系统日历写入或后台通知能力，所以这里没有系统推送。
- 小红书客户端 9.46 及以上优先使用 `window.xhs.miniTool` 的原生存储；更旧版本使用浏览器存储并显示提示。每个原生存储键限制 1 MiB，写入前会检查大小。换设备或清理小红书数据前请先备份。
- 备份导出为 PNG 原图，通过小红书原生接口保存到相册。导入可以选择这张原图，也可以粘贴原版「时笺」导出的 JSON。PNG 含私人记录，请勿公开分享、压缩或截图代替原图。
- 移除了 PWA 清单、Service Worker、`.ics` 日历下载、文件下载及外部网络依赖。HTML 使用外部经典脚本和内嵌 CSS；所有资源留在 ZIP 内。

## 重新打包

在项目根目录运行 `python3 xiaohongshu/build.py`。源文件在 `xiaohongshu/src/`，构建结果在 `xiaohongshu/build/`，上传包在 `xiaohongshu/dist/`。原网页版本的文件没有修改。

已通过 JavaScript 语法检查、小红书打包 Skill 1.6.0 的目录与 ZIP 审计、ZIP CRC 校验、桌面浏览器的移动尺寸预览、备份图片编解码，以及原生存储空值、字符串、对象、迁移与损坏数据的模拟验证。还需在小红书上传后台的模拟器和真机上完成最终验收，特别是相册权限与原生存储。

参考：[小红书小工具开发文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)。
